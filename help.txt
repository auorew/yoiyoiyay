[ <code>HELP v.5.0</code> <i>:</i> <code>2026.11.16</code> ]

<b>/help</b> — show this very message.

<i><b>Any text message</b></i> — the bot will ignore it, unless there's a <b>twitter</b>, <b>pixiv</b>, <b>xiaohongshu</b>, <b>discord media</b>, <b>tiktok</b>, <b>instagram</b> or <b>youtube short</b> link in it, that can be parsed.

If you send <i><b>several</b></i> links at once in one message, <b>all links will be</b> <span class="tg-spoiler"><i>hopefully</i></span> <b>parsed</b>.

The bot <b>can be used in groups and channels</b> to some extent. Commands below have default values depending on where the bot is used.

<i>user</i> values are for users, <i>non-user</i> values are for channels and groups.

[ <code>TOGGLES</code> ]

<b>/include_link</b> (<i>user</i>: <b>off</b>, <i>non-user</i>: <b>on</b>) — toggle this on if you want the bot to use a source link as a caption to messages.

<b>/delete_link</b> (<i>user</i>: <b>off</b>, <i>non-user</i>: <b>off</b>) — toggle this on if you want your source messages for a post to be deleted<code>¹</code>.

<b>/ignore_fw</b> (<i>user</i>: <b>off</b>, <i>non-user</i>: <b>on</b>) — toggle this on if you want the bot to ignore forwarded messages (mainly useful in channel mode).

Specific:

<b>/tiktok_hd</b> (<i>user</i>: <b>off</b>, <i>non-user</i>: <b>on</b>) — toggle this on if you want to get a video in HD quality (may result in large videofile).

<b>/twitter_hd</b> (<i>user</i>: <b>off</b>, <i>non-user</i>: <b>on</b>) — toggle this on if you want to get twitter photos as documents.

<b>/pixiv_hd</b> (<i>user</i>: <b>off</b>, <i>non-user</i>: <b>on</b>) — toggle this on if you want to get pixiv artworks as documents.

<b>/instagram_hd</b> (<i>user</i>: <b>off</b>, <i>non-user</i>: <b>on</b>) — toggle this on if you want to get instagram photos as documents.

Even more specific:

<b>/tiktok_mode</b> (<i>user</i>: <b>video</b>, <i>non-user</i>: <b>video</b>) — toggle this to switch between slideshow tiktok as video or as pack of images (video mode may not work though).

[ <code>STYLE COMMANDS</code> ]

You can use these commands with an integer argument to specify the style you want to switch to. In cases when integer is out of range modulo operation is used. Any other arguments are ignored.

<b>/twitter_style</b> (<i>user</i>: style #<code>3</code>, <i>non-user</i>: style #<code>3</code>) — cycle through the twitter post styles.
Only <code>4</code> styles are available at the moment.

<b>/pixiv_style</b> (<i>user</i>: style #<code>3</code>, <i>non-user</i>: style #<code>3</code>) — cycle through the pixiv post styles.
Only <code>5</code> styles are available at the moment.

<b>/tiktok_style</b> (<i>user</i>: style #<code>0</code>, <i>non-user</i>: style #<code>0</code>) — cycle through the tiktok post styles.
Only <code>5</code> styles are available at the moment.

<b>/youtube_short_style</b> (<i>user</i>: style #<code>0</code>, <i>non-user</i>: style #<code>0</code>) — cycle through the youtube short post styles.
Only <code>6</code> styles are available at the moment.

[ <code>NOTES</code> ]

<code>¹</code>: ⚠️ <b>MESSAGES ARE <i>ALWAYS</i> DELETED</b> ⚠️, even if the bot <i><b>can't</b></i> get the content! <i>Except</i> for the cases with forwarded messages if they're ignored with <b>/ignore_fw</b> option.
